## 1. AI-Agent-Assisted Autonomous UAV using LiDAR, Stereo Vision and Starlink

**Status:** Ongoing MSc dissertation, Durham University  
**Keywords:** UAV, LiDAR, stereo vision, SLAM-style navigation, obstacle avoidance, AI agent, natural-language instruction, Starlink communication

### Project Overview

This project investigates an autonomous UAV system using LiDAR and stereo vision for SLAM-style navigation and obstacle avoidance. The system is being extended with an AI-agent layer that interprets natural-language mission instructions and converts them into structured navigation objectives, safety checks, and autonomous-flight actions.

Starlink-enabled remote communication is included in the thesis direction to support long-range supervision, command transmission, and data transfer under infrastructure-limited conditions.

### Technical Relevance

This project is relevant to Vision-Language-Action research because it connects:

- Visual/spatial perception
- Language-based instruction
- Autonomous decision-making
- Real-time sensing
- Communication-constrained deployment
- Safety-aware action execution

### Main Components

- LiDAR/stereo perception pipeline
- SLAM-style navigation and obstacle awareness
- Trajectory and timing visualization
- AI-agent-assisted mission logic
- Starlink-enabled remote communication concept
- Safety-aware task decomposition

## 3. SLAM and Perception Visualization for UAV Debugging

**Status:** Project development / research-supporting workflow  
**Keywords:** SLAM, LiDAR, stereo vision, trajectory plotting, perception debugging, autonomous systems

### Project Overview

This work focuses on visualization-driven debugging for UAV perception and navigation systems. Instead of treating autonomous navigation as a black-box output, the workflow uses logs, plots, timing checks, point/feature inspection and trajectory visualization to identify failure modes.

### Technical Relevance

This is important for autonomous driving and VLA research because safety-critical systems require interpretable failure analysis, not only model outputs.

### Main Debugging Targets

- Sensor timing mismatch
- Trajectory drift
- Feature instability
- Obstacle-awareness failure cases
- Lighting and texture variation
- Real-world sensing uncertainty

## 4. RF / Energy-Harvesting Demonstrator for Battery-Free Connectivity

**Status:** Research assistant work, Durham University  
**Keywords:** RF energy harvesting, patch antenna, transparent antenna, embedded acquisition, Qt visualization, future communication systems

### Project Overview

This project involved an RF and indoor-light energy-harvesting demonstrator for battery-free connectivity. The system used Wi-Fi-band RF energy harvesting and transparent/patch antenna structures to convert RF signals into measurable electrical signals.

### My Contributions

- Integrated RF-to-DC measurement workflow
- Developed embedded voltage/power acquisition
- Implemented real-time visualization
- Supported demonstration-ready system validation
- Connected antenna-side harvested signals with software-side monitoring

### Technical Relevance

Although this is not a computer-vision project, it demonstrates my ability to work with real sensing and communication systems, which is relevant to autonomous systems requiring robust data acquisition and deployment-aware design.
