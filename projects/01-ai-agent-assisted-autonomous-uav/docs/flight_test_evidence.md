## Evidence boundary

The footage verifies that a physical UAV platform was assembled and flown outdoors. Video alone does **not** establish autonomous navigation, LiDAR/stereo fusion accuracy or VLA capability, so no such result is claimed here. Those claims require synchronized telemetry, calibration records and a documented reference system; the public diagnostic pipeline in Project 03 defines the format and acceptance process for that future evidence.
