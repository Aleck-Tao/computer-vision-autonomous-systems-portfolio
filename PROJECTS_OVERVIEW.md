# Projects Overview

This document summarizes how the three selected projects support my preparation for PhD research in computer vision, autonomous systems and Vision-Language-Action models.

## 1. AI-Agent-Assisted Autonomous UAV using LiDAR, Stereo Vision and Starlink

This project is my main bridge toward VLA-style research. It connects perception, natural-language instruction, autonomous decision logic, safety checks and deployment-aware communication. The current thesis direction uses LiDAR and stereo vision for SLAM-style navigation and obstacle avoidance, with an AI-agent layer for interpreting textual mission commands and Starlink-enabled communication for remote supervision.

**Research relevance:**

- Vision-language-action reasoning
- Language-conditioned autonomous systems
- Safety-aware task decomposition
- LiDAR/stereo perception
- Remote communication and deployment constraints

## 2. Image and Audio Deep Learning Workflows

This project demonstrates the basic machine-learning workflow required for multimodal AI research: dataset preparation, preprocessing, feature extraction, model training, evaluation and error analysis. It is not presented as a large-scale benchmark project; rather, it shows my preparation and learning foundation for future work in VLM/VLA models.

**Research relevance:**

- Deep learning pipeline design
- Image/audio preprocessing
- Model evaluation and failure analysis
- Multimodal-learning readiness

## 3. SLAM and Perception Visualization Debugging Tools

This project shows my emphasis on interpretable engineering validation. Autonomous systems should not be judged only by final outputs; their failures must be diagnosed through trajectories, timestamps, feature stability, sensor timing and logs.

**Research relevance:**

- Safety-critical perception validation
- Sensor timing diagnostics
- Trajectory and drift analysis
- Real-world debugging for autonomous systems
